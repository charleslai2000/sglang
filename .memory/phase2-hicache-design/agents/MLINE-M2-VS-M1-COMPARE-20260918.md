## Part B — Comparison Protocol (CPU-only measurement)

Goal: Compare `qwen35-9b-w4a16` (M1, baseline) vs `omnicoder-9b-gptq-int4` (M2, candidate) **without modifying production port :30000**.

### Protocol Design

1. **Correctness / Semantics (same on-paper prompt):**
   - **Prompt set (deterministic):** 10 canonical prompts (fixed-seed):  
     - `N = "System: When solving mathematical problems, use a calculator. Find x such that 3x + 5 = 0."`  
     - `M = "Rewrite the code: def add(a, b): return a + b"`  
   - **Decoding:** `temperature=0`, `top_k=1`, `top_p=0.0`, `seed=0` (max_tokens=256, max_new_tokens=256), forcing a **deterministic greedy reply**.
   - **Regard:** Tailor for **JSON, code correctness, token duplication**.
   - **Criteria:**  
     - `M1-equiv` = content lexicographically consistent with M1 output.  
     - `M2-equiv` = as above.
   - **Oracle:** `output diff` (ok / garbled/repeating).

2. **Performance (throughput & latency):**
   - **Batches:** N=10 requests, 3 seed per seed (30 total).
   - **Metrics:**  
     - Tokens/output (`tokens/s` = `∑output_tokens / wall_time`)  
     - Latency (`time_to_first_token` per request).
   - **Profile:** No probing beyond measurable times (CPU-only telemetry).

3. **Server endpoints:**
   - **M1:** `/var/run/sglang/qwen35-9b-w4a16.sock` (or `curl http://127.0.0.1:<N>/v1/chat/completions?model=qwen35-9b-local`).
   - **M2:** `/tmp/omnicoder-9b-gptq-int4/` served via a separate SGLang instance on **port 30001** (owner directive: "production on :30000; DEV provider on :30001").

4. **Criteria:**
   - **SemFact accept:** prompt output similarity > threshold (e.g., L2 distance ≤ 0.2).
   - **Throughput:** e.g., TPOT > 80 tokens/s.
   - **Gate pass/fail:** Pass if diff(`content1` == content2).

5. **Bounds (CPU-only):**
   - Max requests: 10 per arm (30 total).
   - Max tokens: 256.
   - Timeout: 2 `/call` timeout per request.
   - Abort condition: Any request > 60s time-to-first-token.
