**Finding 4 (closed):** the 8897 MiB is held by the process tree in this PID namespace. 102/113
processes hold `/dev/nvidia*`, and PID 218072 owns 25 device fds plus 28 device mappings. NVML
reports two **host-namespace** PIDs (`3709554`=120 MiB, `3709747`=8754 MiB) that do not exist in
the container's PID namespace, so their process names render as `[Not Found]`; the default
`nvidia-smi` process table suppresses rows it cannot name, which is why it appears empty. NVML
row sum `120 + 8754 = 8874 MiB` is within 23 MiB of the device-reported 8897 MiB (driver/context
overhead). The running server is the overwhelmingly dominant holder.

**Open 4b:** the exact host-PID → container-PID identity of the 8754 MiB row cannot be proven
