## Enforceable anti-duplication rules

1. **Admission oracle:** admit only if the task names one frontier delta or one acceptance check, cites the predecessor evidence, declares gate/authorization, exact paths/command/timeout/stop condition, and passes a duplicate-key check `(logical deliverable, gate, input hash, acceptance oracle)`. Otherwise reject with the first existing owner.
2. **One active deliverable:** one stable logical task ID and one owner at a time. A review, scout, status check, or writer cannot run concurrently against the same unchanged deliverable.
3. **Retry budget:** set before dispatch: at most one diagnosis, one repair, one independent review, and one rerun per failure class; after two failed attempts, stop and repair the mechanism/oracle. A retry is valid only with a concrete failure cause and changed procedure/input.
4. **Artifact visibility protocol:** child must publish the declared absolute artifact before `done`, read it back, hash/list it, and record status separately from verdict. Missing artifact means F/blocked, never permission to spawn a duplicate “recover/check” task without a changed publication procedure.
5. **Post-failure branching:** classify failure as environment/provenance/fixture/semantic/authorization. Dispatch exactly one corrective branch; do not restart the whole plan. Preserve raw failure and test the bypass before any rerun.
6. **Pre-execution review economy:** review before execution only for behavior changes, authorization boundaries, irreversible loss, instrumentation, or acceptance-forgery risk. For bounded experiments, do minimal safety preflight, execute, then one independent evidence review.
7. **Gate closure:** when a hard gate is NOT_VERIFIED, downstream planning/readiness scans are D unless they directly change the blocked gate. When a semantic review rejects an oracle, prohibit transfer/execution of that package and invalidate all bind/status duplicates.
8. **Scope filter:** unrelated inputs (including T282) are rejected at admission and cannot consume retry budget or become evidence.
