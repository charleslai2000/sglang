## GPU device-selection gotcha (important for later tasks)

`nvidia-smi` numbers the GT 1030 as GPU **0** and the RTX 3090 as GPU **1**
(PCI-bus order), but torch's default CUDA enumeration sees the RTX 3090 as
`cuda:0` and the GT 1030 as `cuda:1`. Concretely:

    default:                        cuda:0 = RTX 3090 (8,6), cuda:1 = GT 1030 (6,1)
    CUDA_DEVICE_ORDER=PCI_BUS_ID:   cuda:0 = GT 1030,         cuda:1 = RTX 3090

`CUDA_VISIBLE_DEVICES=1` alone therefore exposes the **GT 1030**, which is the
wrong card and also makes cuDNN init raise
`cuDNN version 92000 is not compatible with devices with SM < 7.5`. Always
select by UUID (`GPU-2e3ed202-...`), as the established lock convention does
and the activation script does.
