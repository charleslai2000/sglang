# rh-p0c-runtime-provenance

RH P0-C: runtime identity, profile freezes and environment/provenance reconciliation from the opt snapshot.

Source repo, original `.memory` path, branch, full source commit, source Git state, class and SHA-256 are recorded per file in `../archive/MANIFEST.tsv`. Files in this directory are collected copies; source repositories were not modified. Runtime/data payloads are kept under ignored `.memory/data/`.
