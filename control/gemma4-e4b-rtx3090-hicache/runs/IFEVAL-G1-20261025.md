# Gemma 4 E4B IFEval: BF16 vs E5M2 KV

## Protocol

Official `google/IFEval` train split: 541 unique examples (540 physical JSONL lines), snapshot SHA-256 `6a85310ca8ce15eff755aa08a3a4ff931c7e273e7515ebb3c492ea85fd8288f2`. lm-evaluation-harness 0.4.13 and its bundled IFEval task/scorer; 0-shot, greedy (`temperature=0`), `max_gen_toks=1280`, `until=[]`, batch size 1. Every source prompt is one user message; harness token encoding is disabled so it cannot truncate/tokenize the chat payload; SGLang applies the local official Gemma chat template. Radix Cache disabled. Same pinned W4A16 checkpoint and service setup; only KV dtype changed (`bf16` / `fp8_e5m2`). The checkpoint revision and weight SHA are recorded in the G1 evidence set. GPU arms ran sequentially while holding `/tmp/f1-r16b-gpu-exclusive.lock`; services stopped afterwards and GPU returned to 0% utilization / 1 MiB.

## Results

Scored directly from the harness's official per-sample records (541 unique keys in each arm):

| KV | Prompt-level strict | Accuracy | Harness prompt-level loose | Harness instance-level strict |
|---|---:|---:|---:|---:|
| BF16 | 439/541 | 81.15% | 83.55% | 86.93% |
| E5M2 | 444/541 | 82.07% | 84.10% | 87.41% |

Prompt-level loose counts from those same records are BF16 452/541 (83.55%) and E5M2 455/541 (84.10%).

Paired strict outcomes differ on 43 prompts: BF16-only correct 19, E5M2-only correct 24; net +5 E5M2 prompts (+0.92 percentage points). This is a single deterministic paired run; it does not establish statistical or general quality equivalence, and the small difference is not evidence that E5M2 improves quality.

Harness's built-in IFEval summary agrees exactly with the saved per-sample boolean fields. An independent re-invocation of the bundled scorer on those records differs by one prompt in each arm (438/541 and 443/541); a process-isolated replay exceeded the 240-second audit budget, and the one-item discrepancy remains unresolved. Therefore the reported headline is the harness aggregate tied to its saved per-sample metric fields, not the independent replay. Full raw records are retained for audit.

## Public-score context

The published reference figures supplied for comparison are BF16 85.2% and G32 81.9%. Our local BF16 result is 4.05 percentage points below 85.2%; E5M2 is 0.17 points above 81.9%. These are contextual, not protocol-equivalent comparisons: this run uses the pinned QAT W4A16 Gemma 4 E4B checkpoint, local SGLang serving and chat-template handling; the public BF16/G32 model/configuration, harness revision, prompt serialization, tokenizer/template, and generation details have not been established here as identical. Do not infer a G32 reproduction or parity from the numerical proximity.
